# Dra. Maria Angelica — Odontologia

Site institucional estático e responsivo da Dra. Maria Angelica.

## Publicar no Vercel

1. Importe o repositório `IanEichler/Dra-Maria-Angelica` no Vercel.
2. Mantenha o diretório raiz do projeto como `./`.
3. Clique em **Deploy**.

O arquivo `vercel.json` já seleciona o preset **Other** e define `dist` como diretório de saída. Não é necessário informar comando de instalação ou de build.

## Estrutura

- `dist/index.html`: página principal.
- `dist/styles.css`: estilos e responsividade.
- `dist/script.js`: comportamento do menu.
- `dist/assets`: imagens e ícone do site.
